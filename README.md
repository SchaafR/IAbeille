# IAbeille
 Système autonome d’IA embarquée pour la détection visuelle autour de la ruche

 structure de fichier à respecter : 
 /doc -> tous les doccuements a rendre pour le projet (charte, CDC, prez, ...)
 /src -> tous les scipts des differentes parties du projet (.ino) dans un sous dossier à part.
 /tests -> tous les tests et brouillons eventuel.
 /hardware -> PCB, boitier, schémas$
 /data -> dataset (edge impulse ou autre).
