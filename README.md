# IAbeille
 Système autonome d’IA embarquée pour la détection visuelle autour de la ruche

 Structure de fichier à respecter : <br>
 /doc -> tous les doccuements a rendre pour le projet (charte, CDC, prez, ...)<br>
 /src -> tous les scipts des differentes parties du projet (.ino) dans un sous dossier à part.<br>
 /tests -> tous les tests et brouillons eventuel.<br>
 /hardware -> PCB, boitier, schémas<br>
 /data -> dataset (edge impulse ou autre).<br>
